My Money Diary 🌷

วิธีใช้งานบน iPhone:
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง HTTPS static hosting เช่น Netlify Drop หรือ GitHub Pages (ต้องคงทุกไฟล์ไว้ในโฟลเดอร์เดียวกัน)
2. เปิดลิงก์เว็บไซต์ด้วย Safari บน iPhone
3. แตะ แชร์ > เพิ่มไปยังหน้าจอโฮม > เพิ่ม
4. กรอกรายรับและบิล จากนั้นติ๊กว่าจ่ายแล้ว ยอดจะอัปเดตทันที
5. ไปที่เมนูตั้งค่า > สำรองข้อมูลเป็น JSON เป็นประจำ

ข้อสำคัญ: ข้อมูลถูกเก็บใน localStorage ของเว็บบนอุปกรณ์ ไม่ซิงก์ข้ามอุปกรณ์ ไม่เก็บข้อมูลบนเซิร์ฟเวอร์ และจะหายได้หากล้างข้อมูลเว็บไซต์/ลบแอปเว็บ โปรดดาวน์โหลดไฟล์สำรองเป็นระยะ
การเปิดไฟล์ HTML ตรง ๆ จาก iPhone อาจไม่รองรับการบันทึกถาวรหรือการติดตั้งเป็น PWA จึงแนะนำให้เปิดผ่าน HTTPS หลังเผยแพร่
การคาดการณ์เงินเหลือเก็บคำนวณจากรายรับทั้งหมดที่ผู้ใช้จด (รวมรายรับรอเข้า) ลบด้วยบิลทั้งหมด และไม่รวมรายจ่ายที่ยังไม่ได้ลงรายการ
